# SupportPilot

Работающий explainable triage-модуль: классифицирует текст обращения, показывает сработавшие признаки, рассчитывает приоритет и SLA и готовит безопасный черновик ответа.

## Возможности демо

- очередь обращений с приоритетами;
- карточка клиента и полный текст обращения;
- воспроизводимая категория с объяснением решения;
- high/normal/low приоритет и рассчитанный SLA;
- безопасный шаблон ответа по категории;
- имитация ответа оператором;
- показатели SLA и скорости реакции.

## Границы демо

Текущая версия не использует LLM или внешние AI API. Категория и приоритет определяются явными словарными правилами, SLA — таблицей по приоритету, а черновик выбирается из заранее заданных шаблонов. Показатель уверенности — эвристический score правил, а не вероятность модели.
