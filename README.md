# SupportPilot

Прототип системы поддержки, которая классифицирует обращения, определяет приоритет и предлагает оператору черновик ответа.

## Возможности демо

- очередь обращений с приоритетами;
- карточка клиента и полный текст обращения;
- AI-категория и предложенный ответ;
- имитация ответа оператором;
- показатели SLA и скорости реакции.

## Коммерческая версия

Интеграции с email, Telegram и CRM, классификация через LLM, RAG по базе знаний, маршрутизация по отделам, аудит ответов и аналитика SLA.

## Запуск

Откройте `index.html` в браузере.
