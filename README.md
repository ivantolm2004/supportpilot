# SupportPilot

SupportPilot показывает объяснимую первичную сортировку обращений поддержки. Вместо скрытой модели здесь используются явные словарные правила: оператор видит категорию, сработавшие признаки, приоритет, срок реакции и редактируемый шаблон ответа.

[Разобрать своё обращение](https://ivantolm2004.github.io/supportpilot/)

## Пример решения

Для текста «С карты дважды списалась оплата» ядро находит платёжный признак `оплат` и срочный признак `дважды`. Результат воспроизводим: категория `payment`, приоритет `high`, SLA 30 минут и платёжный шаблон ответа.

```text
текст → совпадения правил → категория + priority
                                  ├─ SLA deadline
                                  └─ reply template
```

Неизвестный запрос получает категорию `other`, низкий приоритет и нейтральный ответ вместо случайной уверенной классификации.

## Проверяемость

```bash
npm test
```

Шесть тестов покрывают платёж, продуктовую ошибку, fallback, SLA, безопасный ответ для восстановления доступа и полный triage record. Код правил — [`src/triage.js`](src/triage.js), схема — [ARCHITECTURE.md](ARCHITECTURE.md).

## Как читать показатель уверенности

Это эвристический score совпавших слов и urgent-признаков, а не вероятность ML-модели. Текущая версия не использует LLM, RAG или внешние AI API; она также не получает письма, не отправляет ответы и не хранит историю тикетов. Интеграции, аудит SLA и возможный LLM-классификатор поверх детерминированного fallback — отдельный production-этап.

Для локального запуска откройте `index.html`.
